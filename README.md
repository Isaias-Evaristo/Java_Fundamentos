# Java_Fundamentos

Repositório com exercícios práticos dos fundamentos da linguagem Java.

## Conteúdo

| Pasta | Tópico |
|---|---|
| 01-variaveis-tipos | Variáveis e tipos de dados |
| 02-operadores-aritmeticos | Operadores aritméticos |
| 03-condicional-simples | Condicional simples (if/else) |
| 04-condicional-composta | Condicional composta (if/else if/else) |
| 05-scanner-basico | Entrada de dados com Scanner |
| 06-scanner-double-locale | Scanner com double e Locale |
| 07-operador-logico | Operador lógico (&&) |
| 08-condicionais-exercicios | Exercícios de condicionais: DiaQuente, VerificaMaioridade, SituacaoDoAluno, LimiteDeVelocidade, CalculadoraIMC |
| 09-scanner-exercicios | Cadastros com Scanner: CadastroPessoa, CadastroFuncionario, CadastroVeiculo |
| 10-repeticao-e-switch | Repetição (for) e switch: Tabuada, ParesEImpares, CompraComDesconto |
| 11-variaveis-e-operadores-exercicios | Variáveis e operadores: CadastroFuncionarioFixo, PostoDeCombustivel, PrecoFinalFixo, PrecoComDesconto |
| 12-estoque-e-despesas | Cálculos com variáveis e Scanner: ControleDeEstoque, ControleDeDespesas, PostoDeCombustivelScanner |
| 13-condicionais-aplicados | Condicionais em situações reais: BoletimEscolar, ResumoDoBoletim, ResumoDoClima, DescontoPorValor, ControleDeAcesso |
| 14-pagamentos-e-orcamento | Decisões com if/else: PagamentoAbastecimento, PagamentoCompra, OrcamentoMensal |
| 15-switch-aplicado | Estrutura switch: CentralDeAtendimento, FormaDePagamento |

Os programas com "Fixo" no nome usam valores definidos no código. Os outros pedem os dados pelo teclado com Scanner.

## Como executar

Dentro da pasta de um exercício, compile e rode (troque NomeDoPrograma pelo nome do arquivo):

    javac NomeDoPrograma.java
    java NomeDoPrograma

## Ferramentas usadas

Java, Git e GitHub.
